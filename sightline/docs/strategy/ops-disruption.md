# Ops Disruption: The Third Disruption Is the Install

The first disruption is CAC ($285 vs $1,800 to $2,150). The second is monitoring ($4.17/home/mo vs $30 to $80 retail). The third is written down less often, so here it is in writing: **skill moves to the factory and the agents; labor becomes orchestrated commodity; capacity becomes software.**

An incumbent install is a skilled trade performed at the eave. Ours is a logistics problem with a ladder. The scan captures the skill, the factory embeds it in the kit, the agents orchestrate the crew, and what remains on site is snap, clip, and confirm.

## The numbers

Old model: 8.5 job-hours, 1 install per day per W2 crew. Ops Engine: 2.4 job-hours, 3 installs per day per certified 2-person crew (ops-sim). Verified bottleneck table:

| Install step | Old model (hrs) | Ops Engine (hrs) | Where the skill went |
|---|---|---|---|
| Measure | 1.0 | 0 (scan) | Phone scan before the visit; skill moved to software |
| Cutting | 1.5 | 0 (factory) | Rail cut to length at kitting; skill moved to the factory |
| Mounting | 2.5 | 1.4 (snap-in) | Snap-in rail geometry; skill moved to the product |
| Wiring | 2.0 | 0.4 (connectors) | Pre-terminated connectors; skill moved to the harness |
| Programming | 1.0 | 0.3 (auto-provision) | Scan-derived config; skill moved to the agents |
| QC | (in above) | 0.3 | QC agent gate, photo-verified |
| **Total** | **8.5** | **2.4** | |

Downstream: 109 installs/mo capacity per metro by week 12 vs 27 old model (ops-sim). The installer keeps ~$840/day of $1,350 grossed (est.), which recruits crews faster than any W2 posting. Callback rate modeled 4% vs 11%.

## Comparables (each proves one piece)

- **LeafFilter:** one-day, 2-person gutter crews at national scale prove that a roofline product can be productized into commodity-labor installs.
- **Solar racking:** the rail-then-panel sequence proves that moving precision into a factory-made rail collapses field skill requirements.
- **Uber/TaskRabbit:** software-orchestrated independent labor pools prove that scheduling, routing, and quality scoring can replace employment as the coordination layer.
- **Domino's:** "a logistics company that happens to sell pizza" proves the reframe wins categories. SightLine's install arm is a logistics company that happens to mount cameras.

## The flywheel

Faster install (2.4 hrs) -> lower price and faster scheduling -> more demand -> more installers certified -> denser routes per metro -> less drive time -> faster still. Capacity becomes a software curve (the ops-sim ramp), not a hiring pipeline. Each turn of the wheel also feeds the agents more install telemetry, which tightens kitting and drops the callback rate further.

## Honest limits, with mitigations

1. **Weather days.** Modeled 7% capacity loss. Mitigation: scheduling slack built into the ops-sim ramp; retrofit taps (short visits) backfill weather-shortened days.
2. **2-story lift logistics.** 18 to 25 ft eaves exceed ladder-efficient range. Mitigation: lift-rental partnerships per metro and a distinct 2-story SKU priced to carry the lift cost, so tall homes are margin-correct instead of schedule-wrecking.
3. **Contractor quality variance.** Converted seasonal crews vary. Mitigation: certification gates before first solo install, QC agent photo review on every job, installer tiering with route priority as the carrot, and 90-day callback tracking against the 4% modeled rate.
4. **Funnel dependence on one labor pool.** Christmas-light crews are seasonal and finite. Mitigation: three recruitable pools (Christmas-light, gutter, landscape lighting), all already roofline-adjacent, none load-bearing alone.

The claim, restated without hedging: incumbents treat install capacity as headcount. We treat it as a compile target. That is the third disruption, and it is the one hardest to copy, because it is not a feature, it is an operating model.
