# Power architecture

Everything NEC Class 2. No electrician, ever. The math below is generated by `hardware/electronics/power_budget.py`; if this doc and the module disagree, the module wins and this doc has a bug.

## The one rule that governs everything

Cameras are continuous loads. Permanent-lighting suppliers oversubscribe on duty cycle (not every LED at full white forever); a camera node draws its power every second of every day. So camera budgets never borrow the lights' oversubscription headroom.

## 12V retrofit (SKU 1)

Rules, enforced by the quote engine and the install guides:

- **One camera node per terminal.** Gemstone-class terminal: 5A / 60W. LEDs keep their budget; the node is budgeted at its 12W ceiling on top. One node per terminal keeps worst case under budget with margin.
- **12W node ceiling.** Track node continuous draw is ~7.5W (est.), 12W ceiling covers IR + heater duty + capture bursts. Budget at the ceiling, always.
- **75 ft on 18 AWG.** At 12V/12W, 75 ft round trip drops 0.96V (8.0%), landing 11.04V at the node. Acceptable. Beyond 75 ft: inject.
- **Wide-input buck: 9 to 56V in, 5V/3A out.** >90% efficiency target, surge and reverse-polarity protected. One SKU taps every incumbent rail (12/24/36/48V). If the voltage at the node after drop leaves the 9 to 56V window, inject.
- **Power only.** The tap touches the power conductors. The LED data line passes through a buffer untouched; the node never loads a WS2811-family daisy chain.

(Regenerate: `python3 hardware/electronics/power_budget.py`.) Higher rails make distance a non-issue; 12V is the binding case and drives the injection rules.

### Injection decision tree

1. LEDs + 12W node over the terminal watt budget? Inject.
2. Node run over 75 ft at 12V on 18 AWG? Inject (or step to 16 AWG if 75 to 95 ft and the terminal has watt headroom).
3. Voltage at node outside 9 to 56V? Inject. (Only happens on pathological runs.)
4. Second node needed on a terminal? The second node injects, no exceptions.

Injection kit: its own Class 2 supply near the node, WAGO 221 splice, power only, LED data still passes through.

## 48V clean-sheet rail (SKU 2)

Blind-mate bus in a factory-cut rail. 384W Class 2 supply. Budget model:

- Track nodes 7.5W continuous each, door node 4W, LEDs estimated at 0.85 duty (lights keep their oversubscription; cameras never do).
- Reference: 3 track + 1 door + 160 ft of LEDs = 26.5W cameras + ~174W LEDs = ~201W. Headroom 47.8%, meeting the 45% target with 3+ nodes.
- Worst-case all-white-all-on is still inside the supply; the quote surfaces both numbers.

## Bench and pilot measurement

The 30-night pilot protocol (docs/guides/house-pilot.md) logs rail voltage and node draw from telemetry every 30 s. The power claims above get replaced by measured distributions, not anecdotes.
